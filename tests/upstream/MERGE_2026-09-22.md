Before testing an existing physical-device installation, update its bundled skin
folders as described in `ios/README.md`. The installation marker intentionally
preserves existing skins, so installing the new executable alone leaves old Lua
scripts in place. Back up skins, preserve songs/settings/scores, and migrate any
custom scripts that depend on the removed integer texture API.
